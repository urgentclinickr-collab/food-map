# 어전트의원 근처 맛집

맛잘알 원장님의 숨겨놓은 리스트. 어전트의원 직원들이 직접 다녀와서 추천하는 근처 식당 25곳입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 맛집지도 웹페이지 (음식 종류·평가 필터, 오늘 뭐 먹지 랜덤 추천, 네이버지도 링크) |
| `data.js` | 식당 목록 데이터. 식당을 추가하거나 고칠 때는 이 파일만 바꾸면 됩니다 |

## 식당 고치는 법

`data.js`의 `window.PLACES` 목록에서 한 줄이 식당 하나입니다.

- `group`: 거리 (`near` 가까워요 / `mid` 꽤 걸어야 해요 / `far` 많이 걸어요)
- `meal`: `lunch` 점심만 / `dinner` 저녁만 / `both` 점심·저녁
- `bt`: 브레이크타임 있으면 `true`, 없으면 `false`
- `franchise`: 프랜차이즈면 `true`
- `tags`: `호불호` / `추천` / `강추` 중 하나 + `정갈해요` `푸짐해요` `가성비`
- `memo`: 한줄평

번호는 목록 순서대로 자동으로 매겨집니다.

## GitHub Pages로 게시하기

1. 이 저장소의 **Settings → Pages** 로 갑니다.
2. Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** 를 고르고 **Save**.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.
